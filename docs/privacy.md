# 数据与权限说明

**简体中文** · [English](privacy.en.md)

## 数据流

- 过早客内容、用户信息、最新/最热列表及通知通过用户已有站点登录态读取；通知访问遵循原站行为。扩展不采集密码、Cookie 内容或访问令牌。
- 设置和用户标签存储在 Chrome `storage.sync`；是否跨设备同步由 Chrome 同步状态决定。
- 稍后阅读条目与 Imgur Client ID 存储在 `storage.local`。稍后阅读保存主题元数据，不保存整页正文。
- JSON 备份包含设置、标签和稍后阅读，不包含登录态或 Imgur Client ID。
- 分享图片在本机 Canvas 生成，不向外部分享服务发送主题内容。分享页的头像及正文图片经后台读取，不带 Cookie、不跟随重定向；预览与导出均使用读取后的内联数据。二维码在本机生成。
- 图片表情使用公开图片链接；打开表情选择器或预览时，浏览器会连接对应图片来源（如 i.imgur.com），不发送页面 Referrer。表情代码在用户提交时转换为图片链接；扩展不会自动发帖。
- 只有用户在图片对话框点击上传时，才把选中的图片发送到 Imgur。上传返回公共图片 URL。
- 没有分析统计 SDK、广告 SDK 或自建遥测服务器。

## 权限

| 权限 | 用途 |
| --- | --- |
| `storage` | 设置、标签、阅读列表与本机图床配置 |
| `contextMenus` | 站内选中文本解码、保存主题及设置入口 |
| `https://www.guozaoke.com/*`、`https://guozaoke.com/*` | 在目标站增强页面，并读取站点内容 |
| 可选 `https://api.imgur.com/*` | 用户配置并授权后的图片上传 |
| 可选 `https://*/*`、`http://*/*` 的声明范围 | 为不同公开图片来源预留可选权限；不会一次请求此通配范围。只有分享页列出失败来源后，用户点击才请求所列的精确 origin |

图片读取器拒绝本机、已知内网 IP、凭证 URL、特殊协议与异常端口；该 URL 检查不是 DNS 解析审计。SVG 只作为 `img` 的内联图像源，不作为活动 HTML/SVG 文档插入；脚本和外部子资源遵循浏览器的 [SVG 图像模式限制](https://www.w3.org/TR/SVG2/conform.html#processing-modes)。图片来源授权可在 Chrome 的扩展管理页撤销。

## 清理

设置页可以管理标签、导出备份、清除图床配置。恢复默认只重置设置，不删除阅读列表或标签。卸载扩展由 Chrome 清理扩展本地数据；已经上传到 Imgur 的文件不会因卸载扩展而删除。
