# 数据与权限说明

**简体中文** · [English](privacy.en.md)

适用产品：GuoZaoKe Polish。更新日期：2026 年 10 月 9 日。B 站图床与图片上传条款继续适用。

## 处理的数据与用途

扩展为增强过早客的浏览、阅读与编辑体验，会在浏览器中处理页面中的用户名、头像、主题与回复内容、编辑器草稿，以及用户保存的主题地址、阅读状态和自定义标签。没有作者运营的数据收集服务器，不代表扩展不处理用户数据。

页面内容用于主题预览、回复排版、用户卡片和分享图；用户名与标签用于用户标记；主题地址与阅读状态用于稍后阅读。扩展不读取 Chrome 的全局浏览历史。用户选择的本地图片只用于预览、插入与明确发起的上传。

## 数据流

- 过早客内容、用户信息、最新/最热列表及通知通过用户已有站点登录态读取；通知访问遵循原站行为。扩展不采集原站密码、Cookie 内容或原站访问令牌。当前版本不接受、不保存第三方 API Key，也不把帖子内容发送给任何模型服务。
- 设置和用户标签存储在 Chrome `storage.sync`；是否跨设备同步由 Chrome 同步状态决定。
- 稍后阅读条目、默认图床选择与 Imgur Client ID 存储在 `storage.local`。稍后阅读保存主题元数据，不保存整页正文。
- JSON 备份包含设置、标签和稍后阅读，不包含登录态或 Imgur Client ID。
- 分享图片在本机 Canvas 生成，不向外部分享服务发送主题内容。分享页的头像及正文图片经后台读取，不带 Cookie、不跟随重定向；预览与导出均使用读取后的内联数据。二维码在本机生成。
- 图片表情使用公开图片链接；打开表情选择器或预览时，浏览器会连接对应图片来源（如 i.imgur.com），不发送页面 Referrer。表情代码在用户提交时转换为图片链接；扩展不会在用户未操作时自动发帖。
- 评分助手仅在用户点击帖子工具栏「扫描评分」时运行，评分由本机启发式规则计算，不调用任何模型服务。默认关闭的「评分后发回帖」开启后，扩展会先读取该帖页面，确认当前登录账号与助手账号一致，再以浏览器登录态向 www.guozaoke.com 提交一条公开回帖。Cookie 由浏览器附加，扩展不读取、不保存、不导出 Cookie。助手账号名与已评分楼层记录保存在 `storage.local`。
- 只有用户在图片对话框点击上传时，才把选中的图片发送到所选的 B 站或 Imgur，返回公共图片 URL。上传失败不会自动转交另一个图床。
- B 站上传需单独授权 `cookies` 和 `https://api.bilibili.com/*`。后台仅在主动上传时读取该域对应的 `bili_jct` 防伪 Cookie，并将其作为表单字段发送到固定的 B 站图片上传接口；浏览器随请求携带原有 B 站登录 Cookie。扩展不读取 SESSDATA 内容、不复制或持久化登录 Cookie，不同步、导出或记录防伪标记，不向页面脚本或作者传递凭证；上传不包含发布动态操作。隐身窗口上传被拒绝，避免使用错误的账号会话。请求中只附加公开的浏览器 `User-Agent`，便于 B 站服务端识别客户端类型；浏览器扩展后台 fetch 仍然无法携带页面 `Referer` 与设备指纹头，B 站风控升级后可能出现 HTTP 412，可改用 Imgur。
- 0.5.0 起，编辑器中粘贴或拖放图片会**自动**上传到所选图床，**不弹任何对话框**；占位文本在上传成功后替换为图片链接，失败时移除并提示。自动上传仍使用同一上传接口与同一 Cookie/Imgur Client ID 策略。
- 没有分析统计 SDK、广告 SDK 或自建遥测服务器。
- “隐藏站点广告”仅在过早客页面通过本地样式和 DOM 调整隐藏侧栏推广、已识别的 Google 广告及浮动控件，并恢复广告占位前的页面边距，不新增权限、不发送数据，也不阻止原站广告脚本或网络请求。该设置默认开启，可在控制选项关闭。

## 权限

| 权限 | 用途 |
| --- | --- |
| `storage` | 设置、标签、阅读列表、本机图床配置与会话凭据 |
| `contextMenus` | 站内选中文本解码、保存主题及设置入口 |
| `https://www.guozaoke.com/*`、`https://guozaoke.com/*` | 在目标站增强页面，并读取站点内容 |
| 可选 `cookies` 与 `https://api.bilibili.com/*` | 仅在用户启用 B 站上传后，用于读取上传所需的 B 站防伪 Cookie 与发送选中的图片；可在图床配置中撤销 |
| 可选 `https://api.imgur.com/*` | 用户配置并授权后的图片上传 |
| 可选 `https://*/*`、`http://*/*` 的声明范围 | 为图床与公开图片预留可选权限；不会一次请求通配范围 |

Chrome 的 `cookies` 权限与已授予的主机权限共同生效，并不是针对单个 Cookie 的权限隔离。本扩展的实现只读取上述 B 站防伪标记；不遍历其他网站 Cookie。

图片读取器拒绝本机、已知内网 IP、凭证 URL、特殊协议与异常端口；该 URL 检查不是 DNS 解析审计。SVG 只作为 `img` 的内联图像源，不作为活动 HTML/SVG 文档插入；脚本和外部子资源遵循浏览器的 [SVG 图像模式限制](https://www.w3.org/TR/SVG2/conform.html#processing-modes)。图片来源授权可在 Chrome 的扩展管理页撤销。

## 清理

设置页可以管理标签、导出备份、清除图床配置。恢复默认只重置设置，不删除阅读列表或标签。卸载扩展由 Chrome 清理扩展本地数据；已经上传到 B 站或 Imgur 的文件不会因卸载扩展而删除。

卸载或删除本机记录不会删除已经交给图片服务的数据。

## 有限使用

GuoZaoKe Polish 对用户数据的使用与传输遵守 [Chrome 应用商店用户数据政策](https://developer.chrome.com/docs/webstore/program-policies/user-data)，包括有限使用要求。数据仅用于提供本说明中列出的用户可见功能，不出售给第三方，不用于广告定向，不用于信用评估或借贷决策，也不用于扩展功能无关的目的。作者不通过扩展接收或人工查看用户的浏览内容、标签、草稿或备份。

必要的数据传输包括访问过早客、Chrome 设置同步、加载第三方公开图片、用户明确发起的 B 站或 Imgur 上传。相应服务会按其自身规则处理请求；上传到 B 站或 Imgur 的图片可通过公开链接访问。用户主动向 GitHub 反馈渠道提交的内容会按该渠道的可见性展示，请勿在公开问题中附上密码、私密草稿、Key 或完整备份。
